REVIEW:
Throughout my studies, I’ve honed my skills in software design and engineering, algorithms and data structures, and databases. I’ve also learned to work effectively with others, communicate clearly, and prioritize security in every project I’ve taken on.  I’ve been working on some cool projects, like the Travlr full stack application and some cool enhancements for algorithms and database integration. I’ve been able to design, implement, and improve real-world computing solutions, and I’m proud of what I’ve accomplished.  These projects honed my skills in RESTful API development, NoSQL schema design, database queries, modular refactoring, and efficient algorithms. Each development showed how well I can make trade-offs, advance maintainability, and make sure solutions are scalable and secure.

Whether it was explaining complicated tech ideas to my friends, presenting organized documentation, or writing clear, professional code reviews, I learned to communicate efficiently in various locations.  Another crucial aspect of my personal growth has been fostering a mindset of security.  During my code analysis and improvement efforts, I gained a keen understanding of vulnerabilities, including insufficient authentication mechanisms and unsafe data handling practices.  Through the process of refactoring and redesigning these components, I developed respected experience in developing secure and privacy-aware software that proactively identifies and addresses potential vulnerabilities.
